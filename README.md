## 怎麼用

1. 下載後，先讀檔案內的使用前提醒。
2. 將檔案上傳給你使用的 AI，或複製第 2～4 節貼入對話。
3. 選科目、題數與模式。作答後看解析，不懂就追問。

## 使用提醒

- 自行整理的非官方練習提示詞，沒有官方認證或合作關係。
- AI 可能出錯、捏造來源或漏掉範圍；不保證分數或考試通過。
- AIoT 提示詞聚焦學科，不能取代術科準備。考試規格以當年度官方公告為準。
- 不附官方 PDF、參考書或歷屆題庫。下載得到的官方資料也須確認利用條件；本資源不授予第三方素材的使用權。
- 上傳文件給 AI 前，先檢查個資、帳密、公司機密、素材使用權及服務設定。分享 AI 生成題目前，也要核對內容與來源。
